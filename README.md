# Datascience-Toolbox
This project is aimed at teaching the basics of several tools used for data science

## Dataset
We use the **[Spotify Music]** dataset from Kaggle:
🔗 [https://www.kaggle.com/datasets/...](https://www.kaggle.com/datasets/solomonameh/spotify-music-dataset)


## Research Questions
This project aims to answer the following questions:
1. **Which acoustic characteristics drive a song to become popular?**
2. **Can we predict if a new track will be highly popular based on its audio properties?**
3. **What is the relative importance of different features?**
