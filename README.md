# Datascience-Toolbox
This project is aimed at teaching the basics of several tools used for data science

## Dataset
We use the **[Spotify Music]** dataset from Kaggle:
🔗 https://www.kaggle.com/datasets/yashdev01/spotify-tracks-dataset


## Research Questions
This project aims to answer the following questions:
1. **Which musical characteristics are associated with higher song popularity?**
2. **Which music genres perform best, and what distinguishes their songs?**
